# 解説動画 台本

書式ルール（パーサが解釈する記法）:

- `## <scene-id>` … シーン開始。id はファイル名に使うので半角英数とハイフンのみ。
- `### <見出し>` … スライドのタイトル。
- `- <箇条書き>` … スライドの箇条書き。0 個でも可。
- `key: value` … `emotion`（normal / happy / think）と `speaker`（VOICEVOX の話者 ID）。省略可。
- `> <本文>` … ナレーション。複数行書くと連結される。日本語の記号をそのまま書ける。

ナレーションは 1 シーン 15〜30 秒（およそ 100〜200 文字）に収めると聞きやすくなります。

## scene-01
### Claude Code とは？
- ターミナルで動く AI コーディングエージェント
- ファイル編集とコマンド実行まで自律的にこなす
- 対話しながら開発を進められる
emotion: happy
> こんにちは。今日は、Claude Code を使って解説動画を作る方法についてお話しします。
> Claude Code は、ターミナルの中で動く AI のコーディングエージェントです。
> ファイルを読んで、書き換えて、コマンドを実行するところまで自分でこなしてくれます。

## scene-02
### なぜ「コードで動画を作る」のか
- 動画編集ソフトは AI が触りにくい
- コードなら差分で修正できる
- 台本・音声・映像を分離できる
emotion: think
> ここで大事なのが、動画編集ソフトを使うのではなく、コードで動画を組み立てるという発想です。
> 編集ソフトのタイムラインは、AI が直接触ることができません。
> けれどもコードであれば、三枚目のナレーションだけ直して、という指示がそのまま差分の修正になります。

## scene-03
### パイプラインの全体像
- 台本を書く
- 音声合成で読み上げる
- タイムラインを組み立てる
- 動画としてレンダリングする
emotion: normal
> 全体の流れは四つの段階に分かれています。
> まず台本を書き、次に音声合成でナレーションを作ります。
> その音声の長さから各シーンの尺を決めてタイムラインを作り、最後に動画としてレンダリングします。
> 各段階が別々のファイルになっているので、直したいところだけをやり直せます。

## scene-04
### 口パクはデータから作る
- 音声合成が母音の時間を教えてくれる
- 何秒目にどの口の形かが確定する
- 音量から推定するより正確
emotion: happy
> キャラクターの口パクは、実は推測で作る必要がありません。
> 日本語の音声合成エンジンは、それぞれの音がどの母音で、何秒続くのかという情報を返してくれます。
> ですから、何秒目にどの口の形になるのかを、データとして正確に決めることができます。

## scene-05
### まとめ
- スライドもキャラクターもコンポーネント
- 台本を直せば動画が更新される
- 素材を差し替えれば自分の動画になる
emotion: normal
> まとめです。スライドもキャラクターも字幕も、すべてがコードの部品になっています。
> 台本を書き換えてビルドし直せば、動画がそのまま更新されます。
> あとは立ち絵と声を自分の素材に差し替えれば、あなたの解説動画のできあがりです。
